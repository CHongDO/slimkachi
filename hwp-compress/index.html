한글 파일 용량 줄이기 — HWP·HWPX 문서 안 사진만 압축 (슬림까치, 서버 전송 없이 무료)

한글 파일 용량 줄이기 — 문서 안 사진만 다시 압축

한글 문서가 수십 MB가 되는 이유는 대부분 붙여 넣은 사진입니다. 휴대폰 사진을 그대로 넣으면 한 장에 몇 MB씩 차지하기 때문입니다. HWP(한글 2010 이후)·HWPX 파일을 올리면 문서 안의 JPG·PNG 사진만 꺼내 같은 형식으로 다시 압축하고 제자리에 넣습니다. 용량 우선은 사진 긴 변을 2,000px, 균형은 2,560px까지 줄이고, 화질 우선은 해상도를 그대로 둡니다.

글자·표·서식·쪽 구성은 바이트 하나 바꾸지 않고, 사진이 문서에 보이는 크기와 배치도 그대로입니다. 한글 프로그램이 없어도 브라우저에서 바로 줄일 수 있고, 파일은 서버로 올라가지 않습니다. 한글 프로그램 자체 기능으로 줄이는 방법까지 알고 싶다면 아래 가이드를 참고하세요.

사용 순서

  1. HWP·HWPX 파일을 올립니다.
  2. 왼쪽 [용량 모드]에서 용량 우선·균형·화질 우선을 고릅니다. 문서 안 사진 수가 함께 보입니다.
  3. [적용]을 누르면 줄어든 용량과 문서 안 가장 큰 사진 하나의 전후 비교가 나옵니다.
  4. 받은 파일(원래이름_min.hwp)을 한글에서 열어 확인하고, 원본은 따로 보관하세요.

자주 묻는 질문

한글 프로그램이 없어도 되나요?

네. 브라우저에서 바로 줄이며 결과도 같은 HWP·HWPX 형식으로 드립니다. 결과 확인은 한글이나 한글 뷰어에서 해 주세요.

배포용 문서나 암호가 걸린 문서도 되나요?

암호, 배포용, DRM 보안, 전자 서명이 된 문서는 내용을 바꿀 수 없어 손대지 않고 이유만 안내합니다.

한글 97 파일도 줄일 수 있나요?

한글 97 이전 형식(HWP 3.0)은 지원하지 않습니다. 한글에서 다시 저장한 뒤 올려 주세요.

거의 줄지 않았어요.

사진이 없거나 이미 작은 문서는 줄일 부분이 적습니다. 3%도 줄지 않으면 "줄일 사진이 거의 없는 문서입니다"라고 알리고 원본을 그대로 둡니다.

파일은 브라우저 안에서만 처리되며 서버로 전송되지 않습니다.
