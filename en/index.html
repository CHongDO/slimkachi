Reduce photo, PDF & document size — SlimKachi: compress images, PDFs and Word, PowerPoint and Excel files in your browser without uploading: reduce photo size, resize images, convert HEIC to JPG

Compress images without visible quality loss

Drop a JPG, PNG or WebP photo and SlimKachi makes the file smaller while keeping it looking the same. It starts with the free wins: camera details, dates and GPS location stored in the photo are removed, which reduces the file size without touching a single pixel. Color profiles and orientation stay, because they affect how the photo looks. PNG files are optimized losslessly first.

Instead of using one fixed quality setting, SlimKachi saves the photo at several quality levels and measures how close each one is to the original. It keeps the smallest version you can't tell apart by eye, and separately checks smooth areas such as skies and dark backgrounds, where blocky banding tends to appear.

Pick Smallest, Balanced or Quality depending on what the photo is for. If a photo is already well compressed and can't get smaller without losing quality, you get the original back unchanged.

Resize images by percent, pixels or file size

Reduce the photo size in three ways: by percentage (for example 50%), by exact width and height in pixels, or by a target file size. With “Keep aspect ratio” on, the image is fitted inside the box you enter and never stretched.

Target size is made for upload forms with limits such as “under 500KB” or “max 1MB”. SlimKachi first lowers quality at full resolution, and only reduces the resolution as much as needed. The result is checked against the real file size, and 1KB is counted as 1,000 bytes so it stays safely under the limit.

Images are never enlarged beyond the original. You can save as the original format, JPG, PNG or WebP — and AVIF when your browser supports it.

Convert HEIC to JPG, and other formats

Files aren't filtered by extension. SlimKachi tries to open each file in your browser, so anything your browser can read — JPG, PNG, WebP, BMP, GIF, ICO, AVIF — is accepted. iPhone photos (HEIC/HEIF) and TIFF files need a dedicated decoder, which is downloaded only when you add one of those files and runs entirely on your device.

JPG, PNG and WebP can be saved in their original format. Everything else is converted to a sensible format: HEIC becomes a JPG that opens everywhere, while BMP and TIFF become lossless PNG — often much smaller with exactly the same quality. Animated GIFs keep only their first frame. You can choose a different output format in the settings.

When a photo with a transparent background is saved as JPG, the transparent area is filled with white (or a color you pick), since JPG has no transparency. Converting JPG to PNG keeps the quality but can make the file larger, and it can't bring back detail that was already lost. If a conversion makes the file bigger, you'll see a note on the result.

Compress PDF files

Most of a PDF's size usually comes from the images inside it. Scans and photo-heavy PDFs are often stored at a much higher resolution than screens or printers need, so bringing those images down to a sensible resolution and recompressing them can shrink the PDF to a fraction of its size.

Text, fonts and vector graphics are left alone. Pages are never turned into pictures, so the compressed PDF stays searchable and you can still select and copy text. Text-only PDFs are already small; if one barely shrinks, the original is kept.

Reduce the size of Word, PowerPoint and Excel files

Large DOCX, PPTX and XLSX files are almost always large because of the pictures pasted into them — a few phone photos can turn a short report into a 30MB attachment.

SlimKachi takes out only the photos inside the document, compresses each one in its own format (JPG stays JPG, PNG stays PNG) and puts it back in place. Text, tables, formatting, layout and charts are not touched, and the file format doesn't change. Pictures keep the same size on the page, because the document stores the display size separately. Open the result in Office to check it, and keep a copy of the original.

Compress without uploading

Your files are never sent to a server. Compression, resizing and conversion all run inside the browser you're using right now, and results stay in your device's memory until you download them. That makes it safe for ID photos, contracts and anything else you'd rather not upload.

The only things downloaded from the internet are the program code needed for processing and ads. You can confirm this yourself by opening your browser's developer tools on the Network tab while you process a file.

Frequently asked questions

Is it really free?

Yes. There's no sign-up, no file limit per day and no watermark on the results.

Will my photos look worse?

Every result is compared with the original and only used if it passes the quality check. Use the slider on the result screen to compare before and after, and switch to the Quality mode if you want an even closer match.

How many files can I add at once?

By default you can add up to 30 files, 300MB in total, at once. Photos can be up to about 25 megapixels, and PDFs and documents up to 80MB each. On computers with 8GB of memory or more (as reported by Chrome or Edge), the limits rise to 50 files, 500MB, about 50 megapixels and 150MB. The limits for your device are shown in the upload area. Files are checked the moment you add them, so anything over the limit is skipped with an explanation instead of freezing the page.

How do I resize an image to under 500KB?

Choose Resize → Target size, click “Under 500KB” (or type your own limit) and apply. SlimKachi lowers quality first and reduces resolution only if it has to, then confirms the real file size is under the target.

Can I convert iPhone HEIC photos to JPG?

Yes. Add HEIC or HEIF photos and they're opened on your device, converted to JPG and compressed at the same time — handy when a website or app doesn't accept HEIC.

The result is the same size as the original.

That means the file was already well optimized and couldn't get smaller without losing quality, so the original was kept. If you need it smaller, try resizing or setting a target size.

Can it compress password-protected files?

No. Password-protected PDFs and Office files, and digitally signed documents, are left untouched with an explanation. Remove the protection (if you're allowed to) and add the file again.

Should I keep the original?

Yes. Text and formatting stay the same, but photos are recompressed, so you may want the full-quality version later. For documents, open the result in Office to check it before you send it.

Does it work on my phone?

Yes. It works the same in mobile browsers; processing speed depends on your device.

Files are processed only inside your browser and are never sent to a server.
